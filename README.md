# PAX GNOMANIA

The gnome legion storms Gunpowder, Maryland. You fly the saucer. Suck them up
before they take the town.

## ▶ [PLAY IT IN YOUR BROWSER][play]

A Castle Killscreen game by Anders & Partners.

## About

The lore reskin of [SUCK UP][suckup] — the Roman Ornithopter Corps against a
gnome army, fought across three fronts. Same air-cushion flight, same shared
pressure, different war.

*(Working title: HADRIAN'S ANCIENT AIR FORCE.)*

## How to play

| | |
|---|---|
| **Move** | Arrow keys or **WASD** |
| **Beam** | **SPACE** — hold it over a gnome to lift him |
| **Start / continue** | **SPACE** |
| **Run it again** | **SPACE** or **R** |

**SPACE** from the menu runs the fronts in order — **Gunpowder Falls → Barracks
→ Fort**. **B** drops you straight into the siege.

Two cabinets, by URL: [`?cab=hyscore`](?cab=hyscore) (classical) and
[`?cab=blacksite`](?cab=blacksite) (red).
